── VARIABLE INVENTORY ──────────────────────────────────────────────────────────
Each variable below must be extracted from the AI conversation context or
computed post-call.  Variables use the project's existing template syntax:
  {{ variable_name }}          — simple substitution
  {{ var | default }}          — value or "default" if empty/null
  {% for item in list %}{% endfor %} — iteration over a list

── HEADER ──────────────────────────────────────────────────────────────────────
  {{ Name }}        STR   Candidate full name (from identity verification)
  {{ Date }}        STR   Interview date (call start date/time)
  {{ Score }}       NUM   Overall candidate score out of 5 (aggregated average)
  {{ Cid }}         STR   Candidate ID (system-generated or applicant tracking ID)
  {{ Position }}    STR   Position/job title the candidate applied for
  {{ Summary }}     STR   One-paragraph AI summary of the entire interview

── CANDIDATE PROFILE SECTION ──────────────────────────────────────────────────
  {{ Candidate_Name }}   STR   Full name (confirmed during call)
  {{ Email }}            STR   Email address (collected or confirmed)
  {{ Phone }}            STR   Phone number (collected or confirmed)
  {{ Experience_Years }} STR   Total years of work experience
  {{ Education }}        STR   Highest educational qualification
  {{ Notice_Period }}    STR   Current notice period (e.g. "30 days", "Immediate")
  {{ Salary_Expectation }} STR Expected salary range or figure

── EVALUATION CATEGORIES (C1–C5) ──────────────────────────────────────────────
Each category follows the identical pattern below.  Repeat for C2, C3, C4, C5.

  {{ C1_Title }}    STR  Custom category title (fallback: "Candidate Profile & Verification")
  {{ C1_Desc }}     STR  Short description of what this category evaluates
  {{ C1_Score }}    NUM  Category score out of 5
  {{ C1_Score_5_100round }}  NUM  Score as percentage (e.g. 80 means 4.0/5)

  Aspect 1 (e.g. Identity Verification):
    {{ C1a1_Title }}              STR   Aspect title
    {{ C1a1_Anchor }}             STR   Anchor/definition of what was assessed
    {{ C1a1_Score }}              NUM   Aspect score out of 5
    {{ C1a1_Score_5_100round }}   NUM   Aspect score as percentage
    c1a1_str                      LIST  Strengths
    c1a1_imp                      LIST  Areas of concern
    {{ C1a1_Ev }}                 STR   Evidence paragraph (what the candidate said/did)
    {{ C1a1_Quote }}              STR   Direct quote from conversation

  Aspect 2 (e.g. Position Alignment):
    Same as Aspect 1 with suffix a2 (C1a2_Title, C1a2_Anchor, etc.)

── CATEGORY MAPPING ────────────────────────────────────────────────────────────
  C1 → Candidate Profile & Verification
        a1: Identity Verification  |  a2: Position & Application Alignment

  C2 → Work Experience & Background
        a1: Experience Relevance   |  a2: Career Progression & Achievements

  C3 → Technical Skills & Qualifications
        a1: Skills Match           |  a2: Education & Certifications

  C4 → Communication & Soft Skills
        a1: Verbal Communication   |  a2: Professionalism & Interpersonal

  C5 → Career Fit & Availability
        a1: Logistics & Timing     |  a2: Cultural & Salary Alignment

── HIRING RECOMMENDATION ──────────────────────────────────────────────────────
  Recommendations              LIST  List of dicts with keys:
                                      { "Badge": "hire"|"consider"|"no",
                                        "Text": "explanation" }
  {{ Recommendation_Summary }}  STR  Fallback plain-text summary when no list

── INTERVIEW TRANSCRIPT ────────────────────────────────────────────────────────
  {{ Transcript }}  STR  Full conversation transcript (plain text, newlines ok)

── FOOTER ─────────────────────────────────────────────────────────────────────
  {{ Date }}  STR  Reuse same date as header
